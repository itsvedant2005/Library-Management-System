 📚 Library Management System

 📝 Description
A full-stack web application that helps manage library operations efficiently through separate Admin and Student portals. The system allows users to manage books, track borrowing activities, and maintain library records digitally.

 💻 Technologies Used
-  React.js
-  Node.js
-  Express.js
-  MongoDB
-  JWT Authentication
-  Tailwind CSS

 ⚙️ Working
-  Admin can manage books and students.
-  Students can browse and request books.
-  Books can be issued and returned through the system.
-  JWT authentication ensures secure access for users.
-  All data is stored and managed using MongoDB.

 ✨ Features
-  Admin & Student Login
-  Secure JWT Authentication
-  Book Management
-  Student Management
-  Book Issue & Return Tracking
-  Dashboard with Library Statistics
-  Responsive User Interface
